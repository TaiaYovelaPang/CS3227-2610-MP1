# TeamSync Development Summary — 20 August 2026

## Product direction

TeamSync is a desktop tool for team managers to track attendance and produce fair training duty rosters. The initial product scope included Google Sheets attendance, duty management, roster generation, attendance statistics, important dates, and reminders.

The MVP was narrowed to:

1. Link a Google Sheet.
2. Load attendance for a chosen training date.
3. Add, edit, and delete duties.
4. Generate an attendance-aware duty roster.

## Requirements documented

An **Appendix: Requirements** was added to `docs/DeveloperGuide.md`. It contains the target user, value proposition, and prioritised user stories.

## MVP behaviour agreed

- Attendance values are `1` (present), `0.5` (late/early), and `0` (not attending).
- Only members marked `1` are eligible for duties.
- Duties have a name and required headcount; all duties are treated as the same type.
- The roster prioritises members who have performed the same duty less often.
- Each confirmed member is assigned at most one duty for a given date.
- If total duty slots exceed confirmed attendees, the roster may repeat assignments to cover the remaining duties.
- The selected attendance date must appear as a column header in the Sheet. A missing date results in an error.

## Google Sheets integration

The current MVP reads directly from a public Google Sheet rather than requiring attendance to be pasted into the application.

Expected Sheet format:

| Member | 2026-08-20 | 2026-08-21 |
| --- | --- | --- |
| Amy | 1 | 0.5 |
| Ben | 0 | 1 |

The Sheet must be shared as **Anyone with the link**. The provided Sheet URL was tested successfully: it loaded four confirmed attendees for `2026-08-20`.

## Technology decision

The first browser prototype was replaced at the user's request. The application is now a Java 17 Swing desktop application; the former JavaScript, HTML, and CSS implementation has been removed.

The Java source uses OOP separation:

- `TeamSyncApp`: Swing user interface and interaction handling.
- `AttendanceService`: Google Sheets retrieval and CSV parsing.
- `RosterService`: roster-generation rules and fairness logic.
- `Workspace`, `Duty`, `AttendanceRecord`, and `RosterAssignment`: domain models.
- `WorkspaceStore`: local persistence across application restarts.
